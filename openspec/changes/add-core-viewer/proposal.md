# Proposal

Этап: **M1 · Ядро просмотрщика** (см. [roadmap.md](../../roadmap.md)). Первый шаг на пути замены
стороннего движка в neometria.

## Why

neometria показывает туры через проприетарный движок, который живёт в глобальном `window`, управляется
строками скриптового языка и не может лежать в открытом репозитории. Чтобы заменить его, сначала нужно
ядро: показать сцену тура из одного файла или из граней куба, вращать и масштабировать её, сообщать
хосту о состоянии — независимо от фреймворка и без глобалов.

## What Changes

- Фабрика `createPanoViewer(container, options)` создаёт независимый просмотрщик в контейнере хоста;
  на странице может быть сколько угодно экземпляров; `destroy()` освобождает всё.
- Вход — тур (`tour`): список сцен, стартовая сцена, умолчания вида и ограничений. В этом изменении
  показывается стартовая сцена; переключение сцен и переходы — следующее изменение.
- Источники сцены: одна эквиректангулярная панорама 2:1 одним файлом (слишком большие изображения
  автоматически режутся на несколько текстур) или шесть граней куба по шаблону URL с настраиваемыми
  именами граней; превью в тех же форматах.
- Подмена загрузки изображений функцией `loader` хоста (авторизация, прокси, свой кэш) с отменой
  через `AbortSignal`; по умолчанию — `fetch` с CORS `anonymous` и повтором.
- Вид: `yaw`, `pitch`, `roll`, `fov`, режимы FOV; ограничения FOV, «пикселей на пиксель источника»,
  границ (`auto`, `none`, диапазоны); прямолинейная проекция; `project`/`unproject` между точкой
  сферы или направлением в мире и пикселями контейнера.
- Управление: перетаскивание «тянуть» мышью, пером и пальцем, инерция, колесо, щипок, клавиатура;
  каждый вид управления отключается отдельно.
- Состояние: события `on(name, handler)` и снимок `getSnapshot()`/`subscribe()` для
  `useSyncExternalStore`; валидация тура `validateTour`.
- Ошибки с категорией (что делать хосту) и подробным кодом; `retry()` для кнопки «Повторить».
- Словари значений (`EnumSourceType`, `EnumViewerStatus`, `EnumErrorCode` и другие) вместо «голых»
  строк; строки при этом принимаются наравне с константами.
- React: компонент `<PanoViewer>`, хуки `usePanoViewer` и `usePanoSnapshot` в точке входа
  `@dkukushkin/3d-pano/react`.
- Песочница: страницы vanilla и React на локальных 8K-панорамах владельца (вне git) и гранях,
  нарезанных из них служебным скриптом песочницы.
- Документация для интеграторов: `README.md` и `docs/` на английском.

## Capabilities

### New Capabilities

- `viewer-lifecycle`: создание просмотрщика в контейнере, несколько экземпляров, обновление опций,
  уничтожение, безопасный импорт без DOM, размер и плотность пикселей, доступность, отсутствие WebGL2.
- `tour-config`: структура тура, сцены, умолчания и их наложение, стартовая сцена, валидация.
- `panorama-sources`: эквиректангулярный и кубический источники, превью, нарезка больших
  изображений, загрузчик хоста, проверка URL, повтор и прогресс загрузки.
- `camera-view`: параметры вида, режимы FOV, ограничения, прямолинейная проекция, `project` и
  `unproject`.
- `user-controls`: перетаскивание, инерция, колесо, щипок, клавиатура, включение и отключение.
- `viewer-state-events`: снимок состояния, подписка, типизированные события, ошибки.
- `react-adapter`: компонент и хук React поверх ядра, детерминированная серверная разметка.

### Modified Capabilities

Нет — живых спецификаций ещё нет.

## Impact

- Новый код: `src/**` (ядро и React-адаптер), `scripts/*.unit.mjs` (контракт-тесты),
  `examples/playground/**` (песочница и служебный скрипт нарезки граней).
- Публичный API пакета `@dkukushkin/3d-pano` и `@dkukushkin/3d-pano/react` появляется впервые.
- Зависимости: у ядра — нет; у песочницы — Vite, React, `sharp` (Apache-2.0) только для служебного
  скрипта нарезки граней; в пакет они не попадают.
- `.gitignore`: локальные панорамы песочницы (`examples/playground/public/local/`).

## Вне рамок

| Не входит                                                        | Почему / где будет                                      |
| ---------------------------------------------------------------- | ------------------------------------------------------- |
| Переключение сцен, переходы, предзагрузка                        | следующее изменение `add-scene-navigation`              |
| Хотспоты                                                         | изменение `add-hotspots`                                |
| Плавный поворот к цели, функции плавности, автоповорот           | `add-camera-motion` и этап расширения                   |
| Тайловые многоуровневые источники                                | `add-multiresolution`                                   |
| Частичные панорамы, куб-полоса, цилиндр, плоские, видео          | этап форматов — neometria не нужны                      |
| Рыбий глаз, «маленькая планета», Pannini, архитектурная проекция | этап расширения; архитектура рендера их предусматривает |
| Режим мыши «рулить»                                              | решение владельца: только «тянуть»                      |
| Позиция камеры в мире и параллакс                                | `add-3d-tours`                                          |
