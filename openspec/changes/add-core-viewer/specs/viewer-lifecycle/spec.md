# Spec Delta

## Purpose

Как хост создаёт просмотрщик панорамы в своём контейнере, обновляет его опции и уничтожает его, не
оставляя следов, — на любой странице, с любым фреймворком и при серверном рендеринге.

## ADDED Requirements

### Requirement: Создание просмотрщика в контейнере

Фабрика `createPanoViewer(container, options)` SHALL создать внутри переданного контейнера собственный
корневой элемент с canvas и оверлеем для интерфейса хоста и вернуть объект просмотрщика. Атрибуты и
стили самого контейнера библиотека MUST NOT менять. Проверка: сценарий песочницы.

#### Scenario: Просмотрщик появляется в контейнере

- **WHEN** хост вызывает `createPanoViewer(container, { tour, label })` с контейнером ненулевого размера
- **THEN** внутри контейнера появляется корневой элемент библиотеки с canvas и оверлеем, а стартовая сцена тура начинает загружаться

#### Scenario: Контейнер хоста не меняется

- **WHEN** просмотрщик создан, а затем уничтожен
- **THEN** атрибуты, классы и стили контейнера совпадают с исходными

### Requirement: Независимые экземпляры

Каждый вызов `createPanoViewer` SHALL создавать экземпляр, не разделяющий состояние, обработчики и
ресурсы с другими экземплярами. Библиотека MUST NOT создавать глобальных переменных. Проверка: сценарий
песочницы с двумя просмотрщиками на странице.

#### Scenario: Два просмотрщика на странице

- **WHEN** на странице созданы два просмотрщика с разными турами
- **THEN** вращение одного не меняет вид другого, а события каждого приходят только его подписчикам

### Requirement: Безопасный импорт без DOM

Импорт точек входа `@dkukushkin/3d-pano` и `@dkukushkin/3d-pano/react` SHALL выполняться в окружении без
`window`, `document` и WebGL без ошибок и без обращения к этим объектам. Проверка: контракт-тест в Node.

#### Scenario: Импорт на сервере

- **WHEN** обе точки входа импортируются в Node без DOM
- **THEN** импорт завершается без ошибок, а экспортированные функции доступны

### Requirement: Уничтожение просмотрщика

`destroy()` SHALL удалить созданные библиотекой элементы, снять обработчики и наблюдатели, остановить
отрисовку, отменить незавершённые загрузки и освободить WebGL-ресурсы. Повторный вызов MUST быть
безопасным; остальные методы после уничтожения MUST ничего не делать. Проверка: сценарий песочницы.

#### Scenario: Уничтожение во время загрузки

- **WHEN** хост вызывает `destroy()`, пока изображения сцены ещё загружаются
- **THEN** запросы отменяются через `AbortSignal`, корневой элемент удаляется, события больше не приходят

#### Scenario: Вызовы после уничтожения

- **WHEN** после `destroy()` хост вызывает `setView`, `update` или повторно `destroy`
- **THEN** вызовы не бросают исключений и ничего не меняют

### Requirement: Размер и плотность пикселей

Размер отрисовки SHALL следовать за размером контейнера. Буфер кадра SHALL быть равен CSS-размеру,
умноженному на `min(devicePixelRatio, maxPixelRatio) × renderScale`; по умолчанию `maxPixelRatio = 2`,
`renderScale = 1`. Проверка: сценарий песочницы с изменением размера окна.

#### Scenario: Контейнер меняет размер

- **WHEN** контейнер меняет размер
- **THEN** следующий кадр отрисован в новом размере без искажения пропорций

#### Scenario: Экран высокой плотности

- **WHEN** `devicePixelRatio` равен 3, а опции не заданы
- **THEN** буфер кадра в два раза больше CSS-размера контейнера

### Requirement: Отсутствие WebGL2

Если браузер не может создать контекст WebGL2, просмотрщик SHALL перейти в статус `error` с кодом
`webgl-unavailable` и сообщить об этом событием `error`, не бросая исключение из `createPanoViewer`.
Проверка: сценарий песочницы с отключённым WebGL.

#### Scenario: Нет WebGL2

- **WHEN** просмотрщик создаётся в браузере без WebGL2
- **THEN** `createPanoViewer` возвращает объект, снимок состояния содержит ошибку `webgl-unavailable`, а событие `error` приходит подписчику

### Requirement: Обновление опций

`update(partialOptions)` SHALL применять `label`, `loader`, `controls`, `maxPixelRatio` и `renderScale`
к работающему просмотрщику без пересоздания. Ключ, явно переданный со значением `undefined`, MUST
возвращать опцию к значению по умолчанию. Проверка: контракт-тест разрешения опций и сценарий песочницы.

#### Scenario: Отключение колеса на лету

- **WHEN** хост вызывает `update({ controls: { wheel: false } })`
- **THEN** колесо перестаёт менять FOV, остальные виды управления продолжают работать, сцена не перезагружается

#### Scenario: Сброс опции к умолчанию

- **WHEN** хост вызывает `update({ maxPixelRatio: undefined })`
- **THEN** используется значение по умолчанию 2

### Requirement: Проверка опций

Неверные опции — ошибки программиста — SHALL отклоняться синхронно: не-элемент вместо контейнера и
пустой `label` — `TypeError`, нечисловые, бесконечные или неположительные `maxPixelRatio` и
`renderScale` — `RangeError`. Текст ошибки MUST начинаться с `3d-pano:` и называть опцию.
Проверка: контракт-тест.

#### Scenario: Отрицательная плотность пикселей

- **WHEN** хост передаёт `maxPixelRatio: -1`
- **THEN** вызов бросает `RangeError` с текстом, содержащим `3d-pano:` и `maxPixelRatio`

### Requirement: Доступность корневого элемента

Корневой элемент SHALL быть фокусируемым (`tabindex="0"`), иметь роль `application` и доступное имя из
опции `label`. Проверка: сценарий песочницы и проверка атрибутов.

#### Scenario: Фокус с клавиатуры

- **WHEN** пользователь переводит фокус клавишей Tab
- **THEN** фокус попадает на просмотрщик, а скринридер озвучивает значение `label`
