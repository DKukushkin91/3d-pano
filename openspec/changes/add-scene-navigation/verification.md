# Проверка сценариев add-scene-navigation

2026-10-02. Контракт-тесты — `pnpm test:unit` (246 тестов). Навигатор проверяется в Node с поддельными
сессиями (`scripts/navigation-harness.mjs`). Песочница — встроенный браузер Claude Code на локальных
8K-панорамах владельца, страницы `/` и `/react.html`. Панель браузера была скрыта, поэтому
`requestAnimationFrame` подменялся таймером, а просмотрщик пересоздавался уже после подмены. Указатель
и клавиатура воспроизводились событиями `PointerEvent` и `KeyboardEvent` из консоли.

## Повторная проверка поведения M1

- Повтор после ошибки первой сцены: `retry()` доводит её до `ready`.
- Смена после неудачной первой сцены показывает новую сразу.
- Сломанный тур при создании даёт `invalid-tour` с двумя проблемами.
- Монтирование и размонтирование работают как прежде.
- В консоли нет необработанных ошибок. Ошибки 404 перезагрузки `dist/react.js` в Vite — шум пересборки пакета, а не просмотрщика.
