# Proposal

Этап: **M2 · Сцены** (см. [roadmap.md](../../roadmap.md)). Закрывает строки [parity.md](../../parity.md):

- «Сцены и переходы»:
  - загрузка сцены по имени;
  - сохранение вида и инерции при смене;
  - смешивание;
  - предзагрузка сцены, без опции хотспота: она появится в M3.
- «Анимация и движение»: функции плавности (перенесены из M3 по решению владельца).
- «Что использует neometria»:
  - пересоздание движка при смене ремонта;
  - сцена на каждую пару «комната × вариант»;
  - переход при смене ремонта;
  - смешивание при переходе между комнатами;
  - предзагрузка соседних комнат;
  - флаг «переход начат движком».

## Why

В M1 просмотрщик показывает только стартовую сцену, а смена тура в React пересоздаёт его целиком. neometria
переключает комнаты и варианты ремонта сотни раз за сессию. Ей нужны:

- плавная смена с сохранением направления и инерции;
- предзагрузка соседних комнат;
- смена данных тура без пересоздания движка.

Без этого переезд с проприетарного движка невозможен.

## What Changes

- `viewer.showScene(id, options?)` переключает сцену тура. Промис разрешается `true`, когда переход
  завершён, и `false`, когда вызов перебит следующим или просмотрщик уничтожен. Отклоняется он только при
  ошибке загрузки или неизвестном `id`. Последний вызов побеждает.
- Переходы `cut` (мгновенный) и `blend` (смешивание):
  - смена начинается, когда основное изображение новой сцены готово, а до этого на экране и под
    управлением остаётся старая;
  - смешивание задаётся длительностью и функцией плавности.
- Функции плавности: словарь `EnumEasing` из полного набора in/out/in-out (`linear`, `sine`, `quad`,
  `cubic`, `quart`, `quint`, `expo`, `circ`, `back`, `elastic`, `bounce`) или своя функция
  `(progress) => number`.
- Вид после смены (`view`):
  - `scene` — стартовый вид сцены, по умолчанию;
  - `keep` — текущий вид;
  - явный вид.

  `keepMotion` сохраняет инерцию.

- `viewer.preloadScene(id)` готовит сцену в видеопамяти заранее. Готовые и недавно показанные сцены
  живут в LRU-кэше с бюджетом видеопамяти — опция `sceneCacheMegabytes`, по умолчанию 256. Текущая и
  переходная сцены не вытесняются.
- `viewer.setTour(tour, options?)` заменяет тур без пересоздания просмотрщика. Опции те же, что у
  `showScene`, плюс `scene`. Сцены с теми же источниками остаются в кэше.
- Снимок и события:
  - `snapshot.sceneId` сразу указывает на новую сцену;
  - новое поле `isTransitioning`;
  - новое событие `sceneChange { sceneId, previousSceneId }`;
  - новый код ошибки `unknown-scene` (категория `tour`).
- React:
  - пропсы `scene` и `sceneOptions` применяются при изменении значения `scene`;
  - проп `onSceneChange`;
  - смена пропа `tour` вызывает `setTour` вместо пересоздания просмотрщика (**BREAKING** для поведения
    M1, решение D26).
- Рендер: композитинг через framebuffer. На время смешивания каждая сцена рисуется в свою текстуру
  размером с кадр, а отдельный проход их смешивает. Это основа переходов M4–M6.
- Песочница: кнопки сцен и переходов, предзагрузка, замена тура, React-проп `scene`.
- Документация для интеграторов: `README.md`, `docs/api.md`, `docs/react.md`, `docs/tour.md`.

## Capabilities

### New Capabilities

- `scene-navigation`:
  - переключение сцен и его промис;
  - гонки вызовов;
  - вид и инерция после смены;
  - предзагрузка и кэш сцен с бюджетом видеопамяти;
  - замена тура без пересоздания просмотрщика.
- `scene-transitions`: мгновенная смена и смешивание, длительность, плавность перехода. В M5–M6 сюда
  добавятся другие переходы.
- `easing`: функции плавности — именованный набор и своя функция хоста. В M3 их возьмёт плавный
  поворот камеры.

### Modified Capabilities

- `viewer-state-events`:
  - снимок получает `isTransitioning`, и уточняется смысл `status` при смене сцены;
  - новое событие `sceneChange`;
  - новый код ошибки `unknown-scene`.
- `viewer-lifecycle`: опция `sceneCacheMegabytes` в создании, `update()` и проверке опций.
- `react-adapter`:
  - пропсы `scene`, `sceneOptions`, `onSceneChange`;
  - смена `tour` больше не пересоздаёт просмотрщик.

## Impact

- Код:
  - `src/viewer/**`: навигатор сцен и кэш; `create-pano-viewer.ts` придётся разделить из-за лимита в
    300 строк.
  - `src/render/**`: framebuffer-композитинг и проход смешивания.
  - Новый модуль функций плавности.
  - `src/state/**`, `src/react/**`.
- Публичный API:
  - новые методы `showScene`, `preloadScene`, `setTour`;
  - опция `sceneCacheMegabytes`;
  - словари плавности, типов перехода и режима вида;
  - поле снимка, событие, код ошибки;
  - React-пропсы.

  Существующие сигнатуры не меняются. Меняется поведение React при смене `tour`.

- Тесты: новые `scripts/*.unit.mjs` на плавность, гонки, кэш, разрешение опций и замену тура.
- Зависимостей не добавляется.
- Документы проекта: `parity.md` (имена `showScene`/`setTour` вместо предварительных, плавность в M2) и
  `roadmap.md` (функции плавности переезжают из M3 в M2).

## Вне рамок

| Не входит                                                    | Почему / где будет                                                                      |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| Переходы через цвет, засветку, с приближением, сдвиг, iris   | M6; framebuffer-композитинг этого изменения — их основа                                 |
| Переход-движение в 3D (шаг по полу с размытием и разворотом) | M5 `add-3d-tours`: нужны позиции сцен в мире                                            |
| Навигационные хотспоты и предзагрузка при наведении          | M3 `add-hotspots`; здесь только `preloadScene`, который они вызовут                     |
| Плавный поворот камеры к цели (`lookAt`)                     | M3 `add-camera-motion`; функции плавности из этого изменения он возьмёт готовыми        |
| Приоритеты и отмена загрузок тайлов, бюджет памяти тайлов    | M4 `add-multiresolution`                                                                |
| Переход по умолчанию на уровне тура или просмотрщика         | решение владельца: YAGNI, переход виден в месте вызова                                  |
| `prefers-reduced-motion` для переходов                       | M6, вместе с остальными настройками доступности движения                                |
| Показ превью новой сцены во время смены                      | следует из решения владельца: старая сцена остаётся до готовности основного изображения |
