# Proposal

Этап: **M5 · 3D-туры** (см. [roadmap.md](../../roadmap.md)), второе и последнее изменение этапа после
`add-3d-tours`: WebGL-поверхности хотспотов. Закрывает строки [parity.md](../../parity.md):

- «Хотспоты и интерфейс»: хотспоты, лежащие в плоскости (WebGL-поверхность), видео-хотспоты, учёт глубины.
- «Что использует neometria»: три хотспота на точку — видимый диск рисуется поверхностью.

## Why

Сейчас картинка хотспота в плоскости — DOM-элемент с CSS `matrix3d` поверх canvas. Для меток на полу
neometria этого хватает, но у такого способа есть пределы:

- поверхности не перекрывают друг друга по расстоянию;
- элемент целиком пропадает, если хоть один его угол оказался позади камеры;
- при смешивании и шаге метки старой сцены исчезают рывком, а не гаснут вместе с ней;
- видео на стене комнаты нельзя показать как часть сцены;
- в нелинейных проекциях (M6) и в WebXR (M8) DOM-слоя нет.

Поверхности, нарисованные в WebGL вместе со сценой, снимают эти пределы. Это последний шаг пути
neometria (M1–M5).

## What Changes

- **Поверхность хотспота.** У хотспота в плоскости — из тура и у `addHotspot` — появляется необязательная
  `surface`:
  - картинка `{ image }` или видео `{ video }`;
  - своя ширина `width` в единицах мира, по умолчанию `plane.width`; высота — по пропорциям источника.

  Поверхность рисуется в WebGL в плоскости хотспота: та же точка, `facing`, `spin` и якорь. DOM-элемент
  хотспота остаётся зоной нажатия и фокуса, поэтому клик, наведение, Tab, навигация, предзагрузка и
  события работают как сейчас. Пример для neometria: `plane.width: 0.5`, `surface.width: 0.125` — зона
  нажатия вчетверо шире диска.

- **Источники.**
  - В туре (JSON) — URL картинки или видео.
  - У хоста — ещё и готовый источник: `<img>`, `<canvas>`, `ImageBitmap` или `<video>`.
- **Сеттер.** `setSurface` у хотспота хоста и проп `surface` у `<Hotspot>`.
- **Глубина.** Поверхности перекрывают друг друга по настоящему расстоянию, попиксельно, в том числе
  пересекающиеся. Все они лежат поверх панорамы, DOM-хотспоты — как и сейчас, над canvas. У камеры
  поверхность обрезается и видна частично, а не пропадает.
- **Смена сцен.** Поверхности рисуются вместе с изображением своей сцены: при смешивании и шаге старые
  гаснут и размываются вместе со старой сценой, новые проявляются с новой.
- **Видео из тура.** Играет само, без звука, по кругу, пока его сцена на экране. Когда сцена ушла, видео
  ставится на паузу и освобождается. Нужны звук или управление — хост передаёт свой `<video>`.
- **Загрузка.**
  - Картинки по URL грузятся через `loader` и `retry` просмотрщика.
  - Одна текстура на URL на всех хотспотах.
  - Готовность сцены и `loadProgress` поверхности не задерживают.
- **Песочница.** Метки на полу демо-тура рисуются поверхностями. Добавляются пересекающиеся таблички,
  видео-хотспот тура и видео хоста.
- **Документация для интеграторов:** `docs/tour.md`, `docs/api.md`, `docs/react.md`, `README.md`.

## Capabilities

### New Capabilities

- `hotspot-surfaces`:
  - поверхность хотспота, её размер и положение;
  - глубина и обрезка у камеры;
  - поверхности при смене сцен;
  - загрузка картинок, видео из тура и источники хоста;
  - проверка и освобождение.

### Modified Capabilities

- `hotspots`: «Хотспоты хоста» — поле `surface` у `addHotspot` и сеттер `setSurface`.
- `tour-config`: «Структура тура» — поле `surface` у хотспота сцены.
- `react-adapter`: «Компонент Hotspot» — проп `surface`.

## Impact

- **Код:**
  - чистая геометрия углов поверхности и порядка отрисовки в `src/math/`;
  - слой поверхностей: выбор поверхностей кадра по сценам, текстуры с подсчётом ссылок, видео;
  - проход поверхностей в рендере со своими шейдерами;
  - буфер глубины у canvas (контекст `depth: true`) и у текстур кадра смешивания;
  - проверка `surface` в туре и у `addHotspot`;
  - сеттер в `viewer-hotspots`, проп в `<Hotspot>`.
- **Публичный API:**
  - поле `surface` у хотспота тура и у `addHotspot`;
  - `setSurface` у хотспота хоста;
  - проп `surface` у `<Hotspot>`;
  - типы поверхности;
  - атрибут `data-pano-surface`.

  Существующие сигнатуры совместимы.

- **Память:** буфер глубины добавляет 4 байта на пиксель буфера кадра; текстуры поверхностей не входят в
  бюджеты сцен и тайлов.
- **Тесты:** новые `scripts/*.unit.mjs`:
  - углы поверхности против `project` углов DOM-элемента;
  - порядок отрисовки;
  - выбор поверхностей кадра при смене сцен;
  - учёт текстур с поддельным загрузчиком;
  - проверка `surface`.
- **Зависимости** не добавляются.

## Вне рамок

| Не входит                                                                 | Почему / где будет                                                                  |
| ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| Поверхности в нелинейных проекциях                                        | M6, вместе с проекциями: сетка вместо прямоугольника и проекция в вершинном шейдере |
| Нажатие лучом без DOM, WebXR                                              | M8; сейчас зона нажатия — DOM-элемент хотспота (решение владельца)                  |
| Перекрытие поверхностей панорамой (моделью «пол + сфера») и DOM-хотспотов | решение владельца: глубина только между поверхностями                               |
| Звук и настройки воспроизведения видео в JSON                             | решение владельца: хост передаёт свой `<video>`                                     |
| Встроенные фигуры (диск, рамка)                                           | решение владельца: хост даёт картинку или `<canvas>`                                |
| Поверхность у хотспота без `plane` (лицом к камере)                       | решение владельца: поверхность лежит в плоскости хотспота                           |
| Прозрачность, масштаб и анимации поверхности в API                        | подсветка и пульс — CSS зоны нажатия или новая картинка; добавим, когда понадобится |
| Видео-панорама                                                            | M7                                                                                  |
| `prefers-reduced-motion` для автозапуска видео                            | M6, вместе с остальными настройками движения                                        |
| Потеря WebGL-контекста                                                    | M7                                                                                  |
