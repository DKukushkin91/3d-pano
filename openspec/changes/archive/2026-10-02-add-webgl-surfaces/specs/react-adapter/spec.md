# Spec Delta

## MODIFIED Requirements

### Requirement: Компонент Hotspot

`<Hotspot position scene? anchor? plane? surface?>` SHALL показывать детей в хотспоте хоста через
`addHotspot`: внутри `<PanoViewer>` он берёт просмотрщик из контекста, вне его — из пропа `viewer`. Смена
пропса MUST вызывать его сеттер, размонтирование — `remove`; позицию при вращении ставит библиотека без
перерисовок React. `surface` сравнивается по полям: URL и `width` — по значению, источники-элементы — по
ссылке. Проверка: сценарий песочницы.

#### Scenario: Пины товаров

- **WHEN** хост рендерит `<Hotspot>` для каждого товара комнаты внутри `<PanoViewer>`
- **THEN** карточки стоят в своих точках, переключатель видимости убирает их размонтированием, а вращение не вызывает рендеров

#### Scenario: Табличка в React

- **WHEN** хост рендерит `<Hotspot plane={…} surface={{ image: '/sign.png' }}>` и при каждом рендере создаёт новый объект `surface` с тем же URL
- **THEN** `setSurface` не вызывается, а смена URL вызывает его один раз
