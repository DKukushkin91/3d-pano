# Проверка сценариев add-core-viewer

2026-10-02. Контракт-тесты — `pnpm test:unit` (169 тестов, файлы `scripts/*.unit.mjs`). Песочница — встроенный
браузер Claude Code на локальных 8K-панорамах владельца, страницы `/` и `/react.html`; сценарии с
указателем и клавиатурой воспроизводились реальным вводом инструмента или событиями `PointerEvent` /
`KeyboardEvent` из консоли.
