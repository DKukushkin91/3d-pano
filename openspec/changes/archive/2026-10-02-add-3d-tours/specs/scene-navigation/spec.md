# Spec Delta

## MODIFIED Requirements

### Requirement: Вид после смены

Опция `view` SHALL задавать вид после смены; по умолчанию `'scene'`, а у перехода «шаг» — `'keep'`.
`'scene'` — стартовый вид новой сцены по правилам наложения тура. `'keep'` — текущий вид с `yaw`,
сдвинутым на доворот (разность `heading` сцен или `turn` шага), проведённый через ограничения новой сцены.
Объект вида — его поля поверх стартового вида новой сцены. Вид и ограничения новой сцены MUST применяться
в момент её появления. Проверка: контракт-тест разрешения вида и сценарий песочницы.

#### Scenario: Смена ремонта

- **WHEN** пользователь смотрит на окно (`yaw` 120), и хост вызывает `showScene('kitchen-v2', { view: 'keep' })`
- **THEN** после смены камера по-прежнему смотрит на окно с `yaw` 120

#### Scenario: Явный вид с недостающими полями

- **WHEN** стартовый вид `bedroom` — `{ yaw: 30, fov: 80 }`, и хост вызывает `showScene('bedroom', { view: { yaw: 200 } })`
- **THEN** после смены вид — `yaw` 200, `fov` 80

#### Scenario: Смешивание между комнатами с разным heading

- **WHEN** у текущей сцены `heading: 0`, у `hall` — `heading: 45`, пользователь смотрит на `yaw` 45, и хост вызывает `showScene('hall', { view: 'keep', transition: { type: 'blend' } })`
- **THEN** после смены `yaw` равен 0: направление в мире сохранено

### Requirement: Проверка опций смены сцены

Неверные опции `showScene`, `setTour` и `preloadScene` — ошибки программиста — SHALL отклоняться
синхронным `RangeError` с текстом, начинающимся с `3d-pano:` и называющим опцию: неизвестный
`transition.type`, неизвестное имя плавности, нечисловой, бесконечный или отрицательный `durationMs`,
`view`, не являющийся `'scene'`, `'keep'` или объектом вида, `point` не как у `lookAt`, нечисловой или
бесконечный `turn`, `blur` вне [0, 1]. Проверка: контракт-тест.

#### Scenario: Отрицательная длительность

- **WHEN** хост вызывает `showScene('bedroom', { transition: { type: 'blend', durationMs: -1 } })`
- **THEN** вызов бросает `RangeError` с текстом, содержащим `3d-pano:` и `durationMs`

#### Scenario: Неверный вид предзагрузки

- **WHEN** хост вызывает `preloadScene('bedroom', { view: 'current' })`
- **THEN** вызов бросает `RangeError` с текстом, содержащим `3d-pano:` и `view`

#### Scenario: Размытие больше единицы

- **WHEN** хост вызывает `showScene('bedroom', { transition: { type: 'move', blur: 2 } })`
- **THEN** вызов бросает `RangeError` с текстом, содержащим `3d-pano:` и `blur`
