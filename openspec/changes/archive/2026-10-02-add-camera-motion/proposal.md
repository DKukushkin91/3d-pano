# Proposal

Этап: **M3 · Хотспоты и движение камеры** (см. [roadmap.md](../../roadmap.md)), первое из двух
изменений этапа; `add-hotspots` идёт следом. Закрывает строки [parity.md](../../parity.md):

- «Анимации и автоповорот»: плавный поворот к точке.
- «Что использует neometria»: фокус на пине — поворот 0,9 с `easeOutCubic` с опросом готовности
  каждые 100 мс до 6 с.

Строка «Анимация любых свойств» (подсветка и пульс хотспотов) остаётся за `add-hotspots`.

## Why

Сейчас хост может только мгновенно поставить вид через `setView`. neometria при переходе по ссылке на
товар плавно поворачивает камеру к пину. Для этого она опрашивает движок по таймеру, пока сцена не
готова, и сама считает кратчайший путь по горизонтали. Кроме того, ей нужно гасить такой поворот, если
пользователь схватил панораму. Без плавного поворота с промисом и отменой переезд остаётся с опросом и
ручной математикой у хоста.

## What Changes

- `viewer.lookAt(target, options?)` плавно поворачивает камеру к цели.
  - Цель — новый тип `TViewTarget`: точка сферы `{ yaw, pitch }` или направление и точка мира
    `{ x, y, z }`. Тот же тип получает `project` — его сигнатура по смыслу не меняется.
  - Опции: `fov` (приблизить или отдалить в том же движении), `durationMs` (по умолчанию 900),
    `easing` (по умолчанию `cubic-out`, словарь `EnumEasing` или своя функция из M2), `signal`
    (`AbortSignal` для отмены).
  - Промис разрешается `true`, когда камера доехала, и `false`, когда поворот прерван.
- Анимируются только `yaw`, `pitch` и `fov`; крен и режим FOV не меняются.
- Путь: цель заранее проводится через ограничения сцены, и камера плавно приезжает к ближайшему
  допустимому виду. `yaw` идёт по кратчайшей дуге, а при ограниченном диапазоне `yaw` — внутри него. Цель ровно сзади
  поворачивает камеру в сторону её текущего вращения, а если камера стоит — вправо.
- Прерывание (промис `false`):
  - любой ввод пользователя: нажатие на панораму, колесо, щипок, клавиша управления;
  - `setView` хоста;
  - следующий `lookAt`;
  - `abort()` переданного сигнала;
  - `destroy()`.
- Если ввод уже идёт в момент вызова, `lookAt` сразу разрешается `false` и камеру не трогает. Инерция
  вводом не считается: `lookAt` её гасит.
- Смена сцены ведёт себя как с инерцией. Пока новая сцена грузится, поворот продолжается. В момент её
  появления он прерывается, если не задан `keepMotion: true`. С `keepMotion` поворот продолжается от
  нового вида к той же цели.
- Снимок состояния и события не меняются: ход поворота виден по `viewChange`, конец — по промису.
- Песочница: кнопки поворота к точкам сферы и мира, выбор длительности и плавности, отмена; React-пример
  с `AbortController` в очистке эффекта.
- Документация для интеграторов: `README.md`, `docs/api.md`, `docs/react.md`.

## Capabilities

### New Capabilities

- `camera-motion`: плавное движение камеры по команде хоста — цель, длительность и плавность, путь с
  учётом ограничений, прерывание и отмена. В M6 сюда добавится автоповорот.

### Modified Capabilities

- `scene-navigation`: требование «Инерция при смене» распространяется на плавный поворот —
  `keepMotion` сохраняет и его.

## Impact

- Код:
  - новый чистый модуль интерполяции вида в `src/math/`;
  - новый модуль движения камеры в `src/viewer/`, его шаг идёт в кадре отрисовки рядом с вводом;
  - `src/controls/**`: сигнал «пользователь начал ввод» для прерывания;
  - `src/viewer/create-pano-viewer.ts`: метод `lookAt`, прерывание из `setView` и смены сцены.
- Публичный API: новый метод `lookAt`, типы `ILookAtOptions` и `TViewTarget`. Сигнатура `project`
  переходит на `TViewTarget` — это то же объединение типов. Поведение существующих методов не меняется.
- Тесты: новые `scripts/*.unit.mjs` на интерполяцию, путь по `yaw`, ограничения, прерывание и отмену.
- Зависимостей не добавляется.
- Документы проекта: `parity.md` — имя `lookAt` в строках «Плавный поворот к точке» и «Фокус на пине».

## Вне рамок

| Не входит                                         | Почему / где будет                                                        |
| ------------------------------------------------- | ------------------------------------------------------------------------- |
| Анимация крена и режима FOV                       | решение владельца: в турах не нужна; добавится отдельным изменением       |
| Анимация свойств хотспотов (подсветка, пульс)     | M3 `add-hotspots`; у DOM-хотспотов это CSS хоста                          |
| Движение камеры в мире (смена позиции)            | M5 `add-3d-tours`: у сцен ещё нет позиций                                 |
| Автоповорот                                       | M6; механизм шага движения из этого изменения станет его основой          |
| Скорость в градусах в секунду вместо длительности | решение владельца: постоянная длительность, как у смешивания              |
| Флаг в снимке или события начала и конца поворота | решение владельца: хватает промиса и `viewChange`, без лишних перерисовок |
| Метод остановки любого движения камеры            | решение владельца: отмена через `AbortSignal` конкретного вызова          |
| `prefers-reduced-motion`                          | M6, вместе с остальными настройками доступности движения                  |
