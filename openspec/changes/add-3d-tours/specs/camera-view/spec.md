# Spec Delta

## MODIFIED Requirements

### Requirement: Параметры вида

`getView()` SHALL возвращать `{ yaw, pitch, roll, fov, fovMode, position }` текущего кадра, где `position`
— сдвиг камеры от центра сцены (см. `scene-space`). `setView(partial)` SHALL применять переданные углы и
поле обзора с учётом ограничений сцены; `yaw` MUST нормализоваться в диапазон (−180, 180]. Проверка:
контракт-тест нормализации и ограничений.

#### Scenario: Поворот на полный круг

- **WHEN** хост вызывает `setView({ yaw: 400 })`
- **THEN** `getView().yaw` равен 40

### Requirement: Точка на экране

`project(point)` SHALL переводить точку сферы `{ yaw, pitch }` или точку сцены `{ x, y, z }` относительно
её центра в `{ x, y, isInView }` — CSS-пиксели относительно левого верхнего угла контейнера и признак
попадания в контейнер — и возвращать `null`, если точка позади камеры. Пока камера в центре, у `{ x, y, z }`
важно только направление; при сдвиге точка видна из позиции камеры, а точка сферы лежит на модели сцены.
Проверка: контракт-тест.

#### Scenario: Центр кадра

- **WHEN** вид `yaw` 30, `pitch` 10 и вызывается `project({ yaw: 30, pitch: 10 })`
- **THEN** результат — центр контейнера с `isInView: true`

#### Scenario: Точка сбоку за краем кадра

- **WHEN** вид `yaw` 0, `fov` 90 и вызывается `project({ yaw: 70, pitch: 0 })`
- **THEN** результат правее контейнера с `isInView: false`

#### Scenario: Точка позади

- **WHEN** вид `yaw` 0 и вызывается `project({ yaw: 180, pitch: 0 })`
- **THEN** результат — `null`

#### Scenario: Точка мира во время шага

- **WHEN** камера сдвинута на 1 вперёд, вид `yaw` 0, и вызывается `project({ x: 0, y: -1.5, z: 3 })`
- **THEN** точка видна в направлении `{ x: 0, y: -1.5, z: 2 }` — ниже, чем из центра сцены

### Requirement: Точка сферы под пикселем

`unproject(x, y)` SHALL возвращать точку сферы `{ yaw, pitch }` — направление из центра сцены на точку
модели, изображённую в пикселе `(x, y)` контейнера. Для любой видимой точки `project(unproject(x, y))`
MUST совпадать с `(x, y)` с точностью до 0,5 CSS-пикселя, в том числе при сдвиге камеры. Проверка:
контракт-тест.

#### Scenario: Клик по картинке

- **WHEN** хост вызывает `unproject` для координат клика
- **THEN** получает `yaw` и `pitch` точки панорамы, на которую кликнули

#### Scenario: Клик во время шага

- **WHEN** камера сдвинута, и хост вызывает `unproject` для пикселя, где изображён пол
- **THEN** получает направление из центра сцены на эту точку пола, а `project` того же результата возвращает исходный пиксель
