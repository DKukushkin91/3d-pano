# Проверка сценариев add-3d-tours

2026-10-02. Контракт-тесты — `pnpm test:unit` (488 тестов):

- место сцены в мире и его проверка;
- модель «пол + сфера» и пересчёт между сценами;
- геометрия шага (точка, доворот, сдвиги, размытие);
- опции `move` и вид после смены с доворотом;
- кадры навигатора во время шага;
- `getView().position`, `project` и `unproject` со сдвигом камеры;
- размещение хотспотов со сдвигом;
- навигация и предзагрузка хотспота с шагом;
- видимые тайлы со сдвигом.

Песочница — встроенный браузер Claude Code, страницы `/` и `/react.html`, на локальных 8K-панорамах
владельца. В демо-туре номер стоит в начале координат с `heading: 0`, балкон — в `{ x: 0.2, y: 0, z: -3.9 }` с
`heading: 180`; `cameraHeight` тура — 1.5.

Панель браузера была скрыта, поэтому `requestAnimationFrame` подменялся таймером, а просмотрщик
пересоздавался после подмены. Середину шага ловили длинной длительностью (3–4 с) и снимком экрана.

## scene-space

| Сценарий                              | Чем проверено                                  | Результат                                                                                                                                        |
| ------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Две комнаты в одной системе координат | `scene-place.unit.mjs`, `scene-space.unit.mjs` | центр спальни в осях кухни — `{ 4, 0, 2 }`, её `yaw` 0 — это `yaw` 90 кухни                                                                      |
| Высота камеры для всего тура          | `scene-place.unit.mjs`                         | `hall` — 1.5 из `defaults`, `bedroom` — своя 1.6                                                                                                 |
| Нулевая высота камеры                 | `scene-place.unit.mjs`                         | проблема `scenes[0].cameraHeight`                                                                                                                |
| Позиция строкой                       | `scene-place.unit.mjs`                         | проблема `scenes[1].position`                                                                                                                    |
| Камера в центре                       | `scene-space.unit.mjs`, песочница              | направление выборки — сам луч; неподвижные сцены всех типов рисуются как раньше, кадр после шага совпадает с исходным видом                      |
| Шаг по полу                           | `scene-space.unit.mjs`, песочница              | точка пола `{ 0, −1.5, 3 }` видна из камеры на 1 впереди в направлении `{ 0, −1.5, 2 }`; на снимке середины шага пол и кресла «наезжают» к двери |
| Вне перехода                          | `camera-space.unit.mjs`, песочница             | `getView().position` — нули                                                                                                                      |
| Во время шага                         | `camera-space.unit.mjs`, песочница             | `viewChange` каждый кадр (31 кадр за 500 мс), `position` идёт от точки старой сцены до нуля в осях новой                                         |
| Метка на полу едет вместе с полом     | `hotspot-space.unit.mjs`, песочница            | в пикселе метки изображена та же точка пола; на балконе метка `to-room` меняет `matrix3d` каждый кадр шага                                       |
| Подпись на стене                      | `hotspot-space.unit.mjs`, песочница            | точка сферы стоит там, где изображено её направление; подпись «Sea view» сдвигается во время шага (`translate3d` 101 → −531 px)                  |

## React

ремонта — смешиванием с `keep`; страница собирается (`pnpm check:examples`).
