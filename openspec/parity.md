# Паритет возможностей

Статус: **справочный документ** · 2026-10-01 — этапы соответствуют [roadmap.md](./roadmap.md)

Матрица сравнивает возможности 3d-pano с эталонным коммерческим движком (тем, что стоит в neometria) и
с тем, что реально использует neometria. Возможности описаны своими словами по общеизвестному набору
функций просмотрщиков панорам; чужой код и документация не используются (конституция, принцип I).

Обозначения: **●** — есть/нужно, **○** — нет/не нужно, **M1…M5** — этап из [roadmap.md](./roadmap.md),
**—** — осознанно вне рамок.

## Что использует neometria

Источник — обзор кода `talent.frontends.neometria` (`src/widgets/panorama-tour/`,
`src/entities/room/config/panoramas.ts`, `scripts/lib/equirect-to-cube.mjs`) от 2026-10-01. Файл движка не
открывался.

| Что сейчас                                                                                                           | Как будет в 3d-pano                                                                                  | Этап               |
| -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------ |
| Загрузка скрипта движка тегом `<script>`, глобальная функция, XML в `Blob`-URL, отложенный `revokeObjectURL`         | `import` фабрики, тур — объект JSON, никаких `Blob`-URL                                              | M1                 |
| Пересоздание движка при смене стиля ремонта                                                                          | `setTour`/`showScene` без пересоздания                                                               | M2                 |
| Защита от вызовов после уничтожения (`onBeforeDestroy`)                                                              | методы после `destroy()` — no-op, промисы отклоняются                                                | M1                 |
| Сцена на каждую пару «комната × вариант ремонта»                                                                     | то же, сцены тура                                                                                    | M2                 |
| Тайловый куб: l1 256 без тайлов, l2 1024, l3 2048, l4 4096, тайлы 512, грани `f b l r u d`, тайлы `{row}_{col}.jpg`  | тайловый источник с уровнями и шаблонами URL                                                         | M4                 |
| Эквиректангулярное превью 512×256                                                                                    | превью-источник                                                                                      | M1                 |
| FOV 90 по большей стороне, пределы 70–140, «пикселей на пиксель» 2, автоматические пределы                           | те же опции вида                                                                                     | M1                 |
| Переход при смене ремонта: сохранить вид и инерцию, смешивание 0.3 с, easeInOutSine                                  | `showScene` с сохранением вида и смешиванием                                                         | M2                 |
| Переход между комнатами: смешивание 0.8 с; шаг к точке на полу с размытием 0.5 и разворотом на заданный угол         | смешивание (M2), движение в 3D с разворотом (M5)                                                     | M2, M5             |
| Предзагрузка соседних комнат и при наведении на хотспот                                                              | `preloadScene`, опция навигационного хотспота                                                        | M2                 |
| Три хотспота на точку: видимый диск, прозрачная зона нажатия, подсветка при наведении (анимация прозрачности 0.18 с) | один навигационный хотспот: DOM-элемент на полу с `:hover` в CSS (M3), WebGL-поверхность-фигура (M5) | M3, M5             |
| Увеличенные зоны нажатия на мобильных                                                                                | CSS хоста                                                                                            | M3                 |
| Глобальные колбэки `window.onHotspotClick`/`onHotspotHover`                                                          | события `hotspotClick`/`hotspotEnter` экземпляра                                                     | M3                 |
| Пины товаров: React-оверлей, rAF-цикл, мир → сфера → экран с вычитанием позиции камеры                               | DOM-хотспоты в координатах мира, библиотека позиционирует сама                                       | M1 (`project`), M3 |
| Фокус на пине: поворот 0.9 с easeOutCubic, опрос готовности каждые 100 мс до 6 с                                     | `lookAt(point)` после события готовности сцены, без опроса                                           | M3                 |
| Полоса загрузки из UI-слоёв движка                                                                                   | `loadProgress` в снимке состояния, полосу рисует хост                                                | M1                 |
| Флаг «переход начат движком», чтобы React не прервал переход                                                         | `showScene` возвращает промис, повторный вызов корректно отменяет предыдущий                         | M2                 |
