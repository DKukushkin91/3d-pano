# Check

## Steps

### 1. Прогнать

```bash
pnpm check
```

Порядок шагов внутри: формат → oxlint → политика комментариев → чистая комната → спецификации OpenSpec →
типы → сборка → контракт-тесты → publint/attw → песочница. Упавший шаг останавливает цепочку.

### 2. Починить по причине

- **format:check** — `pnpm format`.
- **lint** — исправь код по правилу; отключать правило нельзя.
- **check:comments** — убери инлайн-комментарий: переименуй сущность или перенеси «почему» в JSDoc
  ближайшего экспорта.
- **check:clean-room** — убери чужое имя API или проприетарный файл из индекса.
- **check:specs** — исправь формат требования (`### Requirement:`, SHALL/MUST, `#### Scenario:`).
- **typecheck / build** — исправь типы без `as`, `any` и `@ts-ignore`.
- **test:unit** — сначала пойми, что нарушено: код или контракт. Контракт меняется только вместе со
  спецификацией.
- **check:package / check:examples** — исправь экспорты пакета или песочницу.

### 3. Повторить до зелёного

Если нарушение нельзя исправить без смены правила или спецификации — остановись и объясни пользователю.
