# Learn Patterns

## Steps

### 1. Определить область

Возьми `$ARGUMENTS`, иначе — по текущему файлу или последним правкам. Если неясно — спроси.

### 2. Прочитать рамки (параллельно)

- `openspec/constitution.md` — принципы;
- `pnpm exec openspec list` и `pnpm exec openspec list --specs` — что в работе и что уже описано;
- `design.md` и `tasks.md` действующего изменения — согласованная архитектура и порядок задач;
- `.claude/reference/RULES.md` — правила кода;
- `package.json`, `tsconfig.json`, `tsdown.config.ts`, `.oxlintrc.json` — сборка и проверки.

### 3. Найти канонический пример той же природы

- чистая логика — модуль без импортов DOM/WebGL и его контракт-тест в `scripts/*.unit.mjs`;
- побочные эффекты — модуль-владелец ресурсов с функцией очистки;
- адаптер — `src/react/*`;
- песочница — `examples/playground/src/*`.

### 4. Свериться с правилами

Пройди по разделам RULES.md, относящимся к области (математика и WebGL, React, качество, комментарии),
и выпиши пользователю 3–5 конвенций, которые будут важны для задачи.

## Rules

- Изучение не меняет файлов.
- Код проприетарных движков не открывать.
- Если найденный паттерн противоречит RULES.md или конституции — сообщи пользователю, не копируй.
